# why long-running agents need checkpoints

When long-running agents crash or get interrupted, checkpoints allow them to resume from their last saved state instead of starting over completely, preventing loss of previous work and maintaining operational continuity. Checkpoints improve resource management by enabling periodic progress saving, which reduces computational costs and allows for better memory and processing allocation compared to restarting from scratch. They are essential for maintaining agent reliability over extended periods because they provide recovery points that protect against system failures and ensure continuous operation without losing accumulated knowledge or progress. This makes checkpoints crucial for agents that need to run continuously for days, weeks, or months without interruption.

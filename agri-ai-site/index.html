🌱 AgInsight

A trustworthy AI farm monitoring agent that validates every alert against its source data before approval.

Capstone · Agentic Systems · Multi-Farm Monitoring

🎯 The Problem

Farmers make time-sensitive decisions from weather and market data. AI can summarize this, but it may invent unsupported statements. A wrong alert means wasted time, money, or poor decisions.

✅ The Solution

AgInsight grounds every alert statement against the original data before delivery. Unsupported claims are removed — so the farmer only sees trustworthy, verified information.

⚙️ How It Works

  1. Collect live weather and commodity data for each location.
  2. Fallback to clearly labeled sample data if an API is unavailable.
  3. Generate alerts from defined thresholds (temp, wind, rain, selected commodity prices).
  4. Ground every statement against the original source data.
  5. Correct once — remove unsupported statements, then re-check.
  6. Approve or hold the final alert.
  7. Log the entire cycle for observability.

🗺️ System Architecture

Data Collection

  • Open-Meteo Weather API (live, per location)
  • Alpha Vantage commodity prices
  • Labeled fallback data on failure
  • OU LiteLLM Sandbox for summaries

Grounding Validation

  • Extreme heat ≥ 100°F
  • Heat advisory 95–99°F
  • High wind ≥ 20 mph
  • Heavy rain ≥ 70% chance
  • Wheat price must match source exactly

Reliability

  • One correction attempt — no endless loops
  • Ground before delivery
  • Graceful API fallback
  • Complete observability log

Trust-First Design

Verified statements reach the farmer; unsupported claims are removed. Farmers stay responsible for every operational decision.
